Personal Job Hunter AI

An AI-powered job discovery and matching system built with Python and local AI models.

Personal Job Hunter AI is an independent software project designed to help job seekers evaluate employment opportunities through AI-powered skill matching and eligibility analysis.

Key Features

- AI Job Matching: Evaluates how well a candidate's skills match job requirements.
- Skill Analysis: Identifies matching and missing skills.
- Eligibility Assessment: Considers candidate eligibility when evaluating opportunities.
- Job Classification: Categorizes opportunities based on their suitability.
- Local AI Processing: Integrates with Ollama to run AI models locally.
- Data Management: Uses SQLite for storing job-related data.

Technology Stack

- Python
- Streamlit
- SQLite
- Ollama
- REST APIs

Project Purpose

The goal is to build a practical AI-powered job hunting assistant that helps candidates make more informed decisions, understand skill gaps, and identify relevant career opportunities.

Development

This project is independently developed and continuously evolving.
